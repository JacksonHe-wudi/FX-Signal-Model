## 3. ⚠️ 未遂事故记录:出口因子的前视 bug

必须记录,因为它差一步就进模型了:

1. 第一版 IMF 拉取的 `TIME_PERIOD` 是 `"2005-M11"` 格式;`pd.PeriodIndex(...)` 把**每年所有月份都解析成该年 1 月**
2. 去重(keep='last')后,留下的是**每年 12 月的数据、盖着 1 月的时间戳** → 年底数据提前 11 个月可见
3. 这个前视版本:IC t **+3.47**,正交化后 t +3.38,进书 paired **+0.174 ± 0.050,十个抖动种子全赢**——通过了我们全部四道检验关
4. 暴露方式:数据面板"停在 2026-01"引起怀疑 → 重拉新鲜数据 → 结果崩塌 → 反查日期解析

教训写成规则:**(a) 新数据接入必须先验证时间戳(逐国 max 日期对照源头);(b) 任何"第一个通过所有关的因子"先假设是 bug,重新拉数、重新解析、隔日复跑之后才算数。** 四道统计关挡不住日期错位——错位造出来的是真实的(假)统计显著。
