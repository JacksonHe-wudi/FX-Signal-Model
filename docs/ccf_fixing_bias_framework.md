# CNH 专属信号 · PBOC 定盘偏差(CCF)多情形框架
**v2 · 2026-07-26 · 数据: L1_country_factors(CNY_FIX, BBG_CNY_FIX) → L2_cny_ccf · 依据: Willer Ch3.6 (Fig 3.5) + 用户实盘经验 + 实证(cnh_fixing_signal.py)**

> 结论先行: CCF **不是线性因子**,更**不是"跟随央行"信号**。实证判定
> (2018-06..2026, 425 周): 它是一个**压力显示器** —— PBOC 逆风而立,
> 定盘偏差暴露的是"风往哪吹",周度口径上**风赢**:
>
> - **跟随 PBOC**(−sign(CCF)): 系统性亏钱, t = **−2.33**
> - **顺底层压力**(+sign(CCF), 加逆势+平静两道门): **+10.6bp/周, 命中 56%,
>   t = +2.86, 9 年中 8 年为正**(仅 2025 微负)
>
> 这正印证用户的实盘解读: "CCF 正 = 有强升值预期, 央行只是不让升那么快"
> —— **底层压力决定方向, 央行只改变节奏**。Willer 的"市场 oblige"适用于
> 日度转折点战术, 周度总回报口径上被压力主导。
> 这也是"每货币微调"的典范: CNH 用自己的 fixing 信号, 不套通用公式。

---

## 1. 观测量定义

```
CCF (fixing bias) = 实际中间价(CNY_FIX) − Bloomberg 定盘调查(FCCNYFIX)
ccf_bp = CCF / 中间价 × 10000      (换算成基点,便于用 10bp 阈值)
```

- `FCCNYFIX` = **Bloomberg CNY fixing survey** —— 市场(金融机构)对当日定盘价的预期。
- 所以 CCF = **PBOC 实际定的 vs 市场以为它会定的**之差 = PBOC 有意注入的"意图偏差"。
- 正 CCF = 定得比预期**弱**(USD/CNY 更高); 负 CCF = 定得比预期**强**。

## 2. 机制(Willer Fig 3.5 + 定盘公式)

定盘公式 = 前收盘 + 篮子稳定 + **逆周期因子(不公开)**。市场每天做的功课就是
反推那个逆周期因子。Willer 的实证:

- **10bp 的 fixing error(5日均)常常导致 CNY 走势转向**——"市场通常照办 (oblige)"。
- 偏差**连续几天、且逆着近期美元方向**时,才是 PBOC 在加大逆周期因子,
  信号含义 = "希望纠正方向、或至少放慢节奏"。
- **平静期**(常态): 游戏是"猜 PBOC 想要什么并跟随",不是跟央行对赌。
- **压力期**(2015 型例外): 市场不听话,PBOC 烧掉 ~1 万亿美元储备才压住。
  此时 fixing 信号**失效**,底层压力最终兑现。

## 3. 四个维度(多情形矩阵)

### A. 方向(符号)—— 实证判定: 顺压力, 不是跟央行
| CCF | PBOC 在做什么 | 暴露的底层压力 | 周度实证含义 |
|---|---|---|---|
| **正**(定得比预期弱) | 压**升值**、不让升太快 | 存在**升值**压力 | 压力兑现 → **看多 CNH** |
| **负**(定得比预期强) | 抗**贬值**、想要更强 | 存在**贬值**压力 | 压力兑现 → **看空 CNH** |

→ 最终逻辑: `sign(未来CNH) ≈ +sign(CCF)`(顺压力)。"跟随央行"(−sign)
经实测系统性亏钱(t=−2.33)—— v1 的一阶假设已被数据推翻并修正。

### B. 幅度门 —— 实测后**弃用**
- Willer 的 10bp 规则是日度 5 日均口径; 周度采样已足够粗, 加 10bp 门
  只滤掉了盈利周(t 从 +2.86 降到 +2.35)→ 首版不用幅度门, 只用符号。

### C. 逆势确认(真逆周期 vs 顺水推舟)
- CCF 与近期 spot 趋势**反向**(spot 在贬、定盘偏强; 或 spot 在升、定盘偏弱)
  = 真·逆周期 → 信号有效。
- CCF 与趋势**同向** = PBOC 只是放行/追认市场 → 信号弱,不触发。
- 判定: `ccf_bp × spot_4w_trend < 0` 才算逆势。

### D. Regime 门(平静 vs 压力)
- **平静期**: 信号可用(市场 oblige)。
- **压力期**: 关掉信号(或研究反向)。识别代理(数据可得性排序):
  1. CNH 1M ATM 隐含波动 z > 1.5(恐慌)
  2. 12M CNH 隐含收益率极端延展(贬值预期堆积, Willer Ch3.6 的 >5% 规则的温和版)
  3. (若有在岸 CNY spot)CNH−CNY basis 走阔

## 4. 信号构造(最终版, 已实证)

```
CNH_fix_signal_t = +sign(ccf_bp_t)                    # A: 顺底层压力
                   × 1{ ccf_bp_t × trend_4w_t < 0 }   # C: 逆势确认(定盘真在逆风)
                   × 1{ vol_z_t < 1.5 }               # D: 平静期门
```
- 输出 ∈ {−1, 0, +1},只对 CNH 生效,并入 CNH 的综合分(作为一个成员信号,
  权重同样走 trailing-IC 自适应)。触发率 ~59%。
- 所有输入均为周五可得(fix 每日 9:15 发布,survey 同日早间,无前视)。

## 5. 实证结果(cnh_fixing_signal.py, 2018-06..2026-07, 425 周)

| 规格 | n | 命中 | 周均 | t |
|---|---|---|---|---|
| **最终版 +sign × 逆势 × 平静** | 251 | 56% | **+10.6bp** | **+2.86** |
| raw +sign, 全部周 | 424 | 56% | +6.9bp | +2.33 |
| 只加平静门 | 381 | 57% | +7.9bp | +2.70 |
| 再加 10bp 幅度门(弃用) | 219 | 56% | +9.6bp | +2.35 |
| 跟随央行 −sign(错误方向) | 424 | 44% | −6.9bp | −2.33 |
| 压力周(被 D 门排除的) | 34 | 50% | +2.1bp | +0.14 |

- 分年: 2018..2026 九年中八年为正(2022 最强 +40.7bp/周; 仅 2025 −7.6bp)。
- 压力周无 edge → 验证 D 门"压力期站开"正确(而非需要反向)。
- 单货币 + 8 年样本, 解读保守; 但方向判定(顺压力 vs 跟央行)在 t≈±2.3 的
  对称对照下是清晰的。

## 6. 已知局限

- 周度采样丢失日内/逐日持续性信息(Willer 用 5 日均); 若日后拉日度 fix
  数据可升级 B 门。
- survey 只回溯到 2018-06,覆盖不了 2015 压力期 → 压力 regime 的失效
  只能靠先验编码,无法样本内验证。
- CCF 幅度 ≠ 强度线性可比: 大偏差可能意味着更强意图,也可能意味着
  市场预期本身混乱(survey 分歧大)。首版只用符号+门,不用幅度加权。
