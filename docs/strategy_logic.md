## 2. 子账本 A:横截面 RV 书(主力)

### 2.1 计算综合分

**第一步:两个成员信号**

```
① carry_to_realvol[t,c] = carry_1m_ann[t,c] / max(已实现波动_1m[t,c], 1.0)
```
- 分子 = 年化 carry(%);分母 = 1M 已实现波动(%),**地板 1%**
- 地板的作用:管理货币安静期波动会塌到 0.1%,不设地板比值会炸到 ±80

```
② esi_chg_4w[t,c] = ESI[t,c] − ESI[t−4,c]
```
经济惊喜指数的 4 周变化。

**第二步:各自横截面标准化**(每周在 14 只货币间做 z)

```
z(x)[t,c] = (x[t,c] − mean_c(x[t,·])) / std_c(x[t,·])
```

**第三步:加权合成 + 平滑**

```
raw[t,c] = (2·z_carry[t,c] + 1·z_esi[t,c]) / (2·1{carry有值} + 1·1{esi有值})
comp[t,c] = z( rolling_mean(raw, 3周) )
```
- 权重 **2:1** 是先验(carry IC 0.073 vs ESI 0.026),**不是拟合的**
- 分母按"实际有值的成员"归一,避免缺数据的货币被系统性压低
- 3 周平滑降换手,最后再做一次横截面 z

### 2.2 选货币(触发器)

```
每周五:
  s = comp[t, :] 中 |z| > 0.5 的货币          # conviction 门
  若 s 中不足 2 只 → 当周空仓
  多头 L = { z 排名前 3 } ∪ { 上周已持有且仍在前 5 }     # 滞回
  空头 S = { z 排名后 3 } ∪ { 上周已持有且仍在后 5 }
  L, S = L−S, S−L                              # 冲突剔除
```
滞回(进 top3 / 留 top5)是为了降换手:一个货币掉到第 4 名不会被立刻踢掉。

### 2.3 定权重

```
腿内:  w[c] = (1/ATM隐含波动[t,c]) / Σ(1/ATM隐含波动)     多头腿 +,空头腿 −
```
每条腿的权重和为 ±1 → **gross 2,net 0(自融资、美元中性)**。低波动货币拿更大名义,使各笔下注的风险贡献接近。

### 2.4 全局杠杆(两层)

```
① dispersion 择时:
   disp[t] = std_c(comp[t,·])                          # 信号分散度
   dz[t]   = (disp[t] − 104周均值) / 104周标准差
   mult[t] = clip(dz[t], −1, +1) × 0.5 + 1.0           # ∈ [0.5, 1.5]

② vol target:
   raw_ret[t] = Σ_c w[t,c]·总回报[t+1,c] × mult[t]
   lev[t]     = min( 5% / (raw_ret 的 52周年化波动), 3 )  ← 滞后一期
```
- **mult**:信号分散度高 = 机会多 = 加仓;分散度低 = 减仓
- **lev**:把整本书拉到 5% 年化波动,上限 3 倍

**最终权重** = `w[t,c] × mult[t] × lev[t] × 50%(风险预算)`

### 2.5 执行

- **方向**:多 = **卖出** USD/CCY 远期;空 = **买入** USD/CCY 远期
- **期限**(混合规则):
  - 在书 ≥4 周的老仓 → **1M**(月度刷新,一个月只付一次点差)
  - 新仓 → 看 basis:`52×1W点数 − 12×1M点数`,选对自己有利的那边
- **成本敏感**:mid 1.37 / 1bp 1.15 / 2bp 0.93 / 5bp 0.28(1W 周roll);1M 在 ≥1bp 时更优

## 3. 子账本 B:EM beta vs 融资篮子

### 3.1 逻辑

MS Beyond Carry 的核心发现,在我们数据上复现:**同一条 EM 多头篮子,只换计价篮子**——

| 融资腿 | Sharpe | maxDD |
|---|---|---|
| 100% USD | **−0.11** | −14.7% |
| 50% CAD + 50% G3 | **+0.66** | **−4.5%** |

2013 年后纯美元融资的 EM beta 是死钱;换成篮子就变成正的,回撤砍 2/3。

### 3.2 计算

```
多头腿(EM 篮子,等波动):
  w_EM[c] = (1/max(已实现波动[t,c],1)) / Σ(...)         14 只货币

空头腿(融资篮子,固定):
  CAD 50%,USD 16.7%,EUR 16.7%,JPY 16.7%

vol target:
  lev_B[t] = min( 5% / (篮子收益的 52周年化波动), 3 )
```

**最终权重** = `w × lev_B × 25%`

### 3.3 执行

- 全部用 **1M 远期**,**月度一起 roll**
- **被动常开**——DXY 趋势择时测过(只在美元下行期持有):0.45 < 静态 0.58,**不加分**,所以不做择时
- 已知盲点:综合分每周横截面 z 化后整体观点被归零,所以 B 目前没有"何时该重仓 EM"的开关。要做需要一个 z 化前的聚合信号(待建)

## 4. 子账本 D:CNH 定盘偏差

### 4.1 观测量

```
CCF[t] = (实际中间价 CNY_FIX[t] − 彭博定盘调查 FCCNYFIX[t]) / CNY_FIX[t] × 10000   [bp]
```
= PBOC **实际定的** vs **市场以为它会定的**之差。

### 4.2 方向(实证判定,和直觉相反)

| CCF | PBOC 在做什么 | 暴露的压力 | 交易方向 |
|---|---|---|---|
| **正**(定得比预期弱) | 压升值、不让升太快 | 存在**升值**压力 | **做多 CNH** |
| **负**(定得比预期强) | 抗贬值 | 存在**贬值**压力 | **做空 CNH** |

**关键实证**:跟随央行(−sign)系统性亏钱 t=−2.33;**顺底层压力**(+sign)t=+2.86。央行改变节奏,改变不了方向。

### 4.3 两道门

```
signal[t] = +sign(CCF[t])
            × 1{ CCF[t] × spot_4周趋势[t] < 0 }        # 逆势确认:定盘真在逆风
            × 1{ CNH 1M ATM vol 的 z < 1.5 }           # 平静期:压力期站开
```
- **逆势门**:定盘偏差要和近期 spot 走势相反,才是真逆周期;同向只是追认市场
- **平静门**:压力周实测无 edge(+2.1bp, t≈0),关掉

触发率 ~59%,单周期望 +10.6bp,命中 56%,9 年中 8 年为正。

### 4.4 执行

- **USD/CNH 1W 远期,单腿**,周度 roll
- 规模 = `sign × lev_D × 25%`,其中 `lev_D = min(5%/CNH年化波动, 3)`
- ⚠️ **注意**:CNH 波动很低(管理货币),所以 vol-target 会给很大名义(近期约 60% of book)。风险口径上是 25%,但**名义集中度高**——如果 CNH 脱离管理区间会有尾部风险,平静门只用 vol z 来防,不一定够

## 5. 每周执行流程

```
周五收盘后:
  1. 更新数据 → python3 data_pipeline_v2.py <xlsx> data/clean
  2. 完整性门:14 只货币逐个检查核心输入,缺的置 NaN
  3. 出执行表 → python3 run_weekly_all.py
       A: 每只货币的 z、方向、权重、在书周数、期限建议
       B: EM 篮子 14 条腿 + 融资篮子 4 条腿的权重
       D: CCF 读数、两道门状态、CNH 仓位
  4. 下单:
       A 新仓/调仓 → 1W 或 1M 远期
       A 老仓(≥4周)→ 到期时用 1M 续
       B → 月度 roll 日一起做
       D → 1W 远期,每周 roll
```

## 8. 诚实的保留

1. **样本内构造**:所有信号定义、门限、权重都在这个样本上定的。**样本外合理预期 1.2–1.5**,不是 1.56。
2. **D 只有 2018-06 起**(彭博调查历史起点),之前实际是 A+B。
3. **A 的成本敏感度**:5bp 时 1W roll 掉到 0.28。你的真实点差决定用 1W 还是 1M。
4. **D 的名义集中度**:风险 25%,但名义可能 60%,CNH 脱钩是未防住的尾部。
